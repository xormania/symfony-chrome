# Fixture application

Created 2026-11-09. Minimal Symfony 8.1 consumer for the packages in `../../packages`. It has no UXor dependency (spec D-02, PKG-01).

Only `composer.json` and `src/Controller/ReadyController.php` are hand-written. The rest of the skeleton is generated by Symfony Flex recipes the first time `bin/dev up` runs `composer update` in a workspace copy.

After the first successful `up`, copy the generated skeleton and `composer.lock` back from `workspaces/dev/app/` into this directory and commit them. From then on every workspace installs from the lock. Do not run Composer in this directory directly; the path repositories point at `/packages`, which exists only inside the container.
